# **App Name**: My Cockpit

## Core Features:

- Dashboard: Dashboard providing a quick overview of tasks, tokens, and expenses.
- Tasks: Task management with deadlines and filtering by projects/priorities. Use tags for quick categorization.
- Projects: Project pages with notes, files, progress tracking, and API links. Features a timeline and automatic linking to related tasks.
- API & Tokens: Securely store tokens, API details (Keys/Secrets/Endpoints), and a quick copy button for any code or key.
- Snippets & Tools: Collection of pre-made code snippets, technical notes, and links to frequently used tools. A small library for fonts or UI files.
- Finance: Personal budget tracking (income, expenses, savings) with a record of financial transactions, invoice uploading, and Excel export. Simple charts to track money flow.
- Ideas Hub: Capture quick notes for any idea. Ability to convert an idea directly into a project or task. Support for uploading images or explanatory files.

## Style Guidelines:

- Primary color: Saturated blue (#4285F4), providing a sense of trust and organization.
- Background color: Light gray (#F5F5F5) offering a clean and modern look.
- Accent color: Green (#34A853) to highlight positive actions and key performance indicators.
- Headline font: 'Space Grotesk', sans-serif, to maintain a computerized, techy look
- Body font: 'Inter', sans-serif, suitable for body text, giving a modern neutral feel
- Simple, professional icons to represent different sections and actions.
- Clean and structured layout to prioritize information. Use of cards and lists to display data effectively.
